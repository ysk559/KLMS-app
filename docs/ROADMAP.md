# ロードマップ

## Phase 1 — 基盤 + 主要画面(このリポジトリの現状)

- [x] Flutter プロジェクト雛形(Android / iOS)
- [x] テーマ(#021951, Material 3, ライト/ダーク/システム追従)
- [x] 多言語(日本語 / 英語 / フランス語)
- [x] 5タブシェル(ホーム / 課題一覧 / ページ / 時間割 / 設定)
- [x] WebView ログイン + Cookie 永続化(ID/Pass非保存)/ アクセストークン方式も選択可
- [x] Canvas API クライアント(コース・課題・提出状態・アナウンス・モジュール)
- [x] sqflite キャッシュ + 差分同期
- [x] 課題一覧(LMS完了反映・手動完了・矛盾検知)
- [x] コース略称([Jexp]表示)
- [x] コースページ(モジュール展開・アイテムをアプリ内WebViewで閲覧)
- [x] 時間割(コース名パース・1コマ2授業の上下分割・3つ以上は「…」)
- [x] 締切リマインダー(n時間m分前・除外ワード・除外コース)
- [x] 設定画面一式
- [x] GitHub Actions CI(analyze + test + Androidビルド + iOSビルド(無署名))

- [ ] アプリ内ブラウザからのファイルダウンロード/PDFビューア改善

## Phase 3 — ウィジェット・外部連携

- [x] ウィジェット用データ基盤(同期のたびに home_widget 経由で
      タスク/時間割スナップショットを書き出し)
- [x] Android ウィジェット3種(次の授業 / 今日の時間割 / タスク一覧、
      ダーク対応・現在コマ強調・タップでアプリ起動)
- [ ] Android: 全体時間割ウィジェット(グリッド描画)
- [x] iOS: WidgetKit 拡張(時間割: 小=次の授業/中=今日/大=週全体、
      課題一覧: 中/大)。実機でのデータ共有には App Group
      `group.jp.keio.klms.klmsApp` の有効化(Apple Developer Program加入後、
      Signing & Capabilities で自動生成)が必要
- [ ] Apple Watch コンプリケーション(次の授業)
- [x] Google Calendar 同期(課題締切の書き込み。ユーザー側で
      Google Cloud OAuth クライアント作成が必要)
      (OAuthクライアント設定済み、実機検証待ち)
- [ ] iOS 26+ Liquid Glass 対応(ネイティブウィジェットのマテリアル)
- [ ] iOS課題ウィジェットのタップ完了(iOS 17 AppIntents、App Group有効化後)

# ユーザーへの確認事項・提案

実装を進めるにあたり採用した前提と、確認したい点をまとめる。
回答をもらい次第、このファイルを更新していく。

## 要確認(重要度順)

### 1. iOS のビルド・配布方法
Mac がないため、iOS のビルドは GitHub Actions(macOS ランナー、無料枠あり)で行う
構成にした。ただし **実機 iPhone へのインストール**には次のいずれかが必要:

- **Apple Developer Program(年間 ¥12,980)** に加入 → TestFlight で配布(推奨・一番楽)
- 無料 Apple ID + **AltStore / Sideloadly** でサイドロード(7日ごとに再署名が必要)

→ どちらの方針にするか教えてください。Android は実機で `flutter run` するだけなので問題なし。

### 2. KLMS でアクセストークンの手動発行が可能か
KLMS にブラウザでログインし、「アカウント → 設定」の下部に
「**+新しいアクセストークン**」ボタンがあるか確認してほしい。

- **ある場合**: トークン認証が使える。セッション Cookie より長寿命で、
  バックグラウンド同期の安定性が大きく上がる(推奨)。
- **ない場合**: Cookie 方式のみ。Okta セッションが切れる周期(体感で何日か)も
  分かると設計の参考になる。

現状は両対応で実装済み(設定画面でトークン入力可)。

### 3. アナウンスのプッシュ通知の即時性
ID/Pass やセッションを外部サーバーに預けない方針のため、通知はすべて
**端末内で完結するローカル通知**にしている。この場合:

- 締切リマインダー: 事前にスケジュールするので**正確な時刻に発火する**(問題なし)
- アナウンス通知: バックグラウンド同期(Android: 15分〜、iOS: OS任せで不定)の
  タイミングに依存し、**数十分〜数時間遅れることがある**(特に iOS)

リアルタイム通知が必須なら中継サーバー(認証情報を預かる形)が必要になるが、
プライバシーとサーバー維持費の観点から非推奨。**ローカル方式で了承いただけるか?**

### 4. 完了矛盾通知のタイミング
「ユーザー完了 ∧ LMS未完了」の通知は、仕様どおりだと手動チェック直後の同期でも
毎回検知されてしまう。現状は「**課題ごとに1回だけ通知**(LMS側が完了になったら
リセット)」とした。これで良いか?
(代案: 締切の24時間前を切った時点でまだ未提出の場合のみ通知、など)

### 5. Google Calendar 同期(Phase 3)
Google Cloud Console で OAuth クライアント ID の作成(無料・ユーザー作業)が必要。
Phase 3 着手時に手順を案内する。

### 6. 問い合わせ先
設定画面最下部の「お問い合わせ」のリンク先(メールアドレス / Instagram /
Google Form の URL)を教えてください。現状はプレースホルダ。

## 採用した前提(異議があれば変更可)

- **時限のデフォルト**: 月〜金・6限、慶應の標準時間
  (1限 9:00–10:30 / 2限 10:45–12:15 / 3限 13:00–14:30 / 4限 14:45–16:15 /
   5限 16:30–18:00 / 6限 18:10–19:40)。設定で曜日範囲・コマ数・各時限の時刻を変更可。
- **「LMS上で完了」の判定**: まず提出状態(submitted/graded)で判定。
  Canvas の ToDo リストの「完了にする」(planner override)は Phase 2 で対応。
- **表示言語**: 日本語・英語に加えてフランス語も実装済み。
- **課題の取得範囲**: ダッシュボードではなく**各コースの課題API**から取得するため、
  ダッシュボードに出ない課題も一覧に含まれる(要望どおり)。

## 追加提案(競合アプリ超えのために)

1. **課題詳細のオフラインキャッシュ**: 電波のない場所でも課題内容・締切を確認可能に
2. **時間割からコースページへのタップ遷移**(実装済み)
3. **「今日のダッシュボード」ウィジェット**: 今日の授業+今日締切の課題を1枚に
4. **提出忘れ防止の"最終警告"**: 締切1時間前になっても未提出(LMS基準)の場合の追い打ち通知
5. **成績(スコア)表示ページ**: Canvas の成績APIから取得(Phase 4)
6. **課題タイトルの正規表現フィルタ**(除外ワードの上位版・上級者向け)
